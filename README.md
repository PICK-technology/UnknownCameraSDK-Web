# UnknownCameraSDK-Web

Local toolkit for discovering, identifying and managing IP cameras.

## Goals

- Local network camera discovery
- Camera identification
- ONVIF support
- RTSP stream discovery and diagnostics
- HTTP/CGI support for compatible cameras
- PTZ through confirmed ONVIF capabilities
- Local browser-based Web UI
